# BusNow!! の世界観

## ひとことで

BusNow!! は、検索アプリではない。富士見台と溝の口駅南口のあいだ、その一区間だけを映す**停留所の看板**である。

## 誰が、どこで開くか

開く人は、高津の坂の上に住んでいて、溝の口までバスで出る人。あるいは駅で降りて、富士見台まで帰る人。経路は最初から決まっている。知りたいのは「どのバスを探すか」ではなく、「いま立っている停留所から、次のバスはいつか」だけ。

だから画面の先頭に検索欄はない。地図もない。停留所名の入力もない。立っている場所を、看板の二枚から選ぶ。

## 二つの看板が、別の答えを返す理由

- **富士見台発**は、途中の停留所である。バスはすでに道のどこかを走っている。必要なのは時刻表の数字ではなく、**あと何分でこの停留所に来るか**。東急バスと川崎市バスの両方を、近い順に全部出す。
- **溝の口駅南口発**は、この区間の**出発電車ならぬ出発停留所**である。ここから富士見台へ向かうバスは、ここを始発にして出ていく。走ってくるバスを待つ停留所ではないので、リアルタイムの接近は使わない。東急バスと川崎市バスの公式時刻表を、平日・土曜・休日で読み、富士見台方面の**次の3本**だけを混ぜて出す。

同じ「発」でも、途中停留所と始発停留所では見るものが違う。その違いを、アプリの構造そのものにする。

## 見た目

夜の停留所。アスファルトの暗い地面に、ホーローの白い看板が二枚かかっている。

- 地面: `#241c16`。街灯の届かないアスファルト。
- 看板の地: `#f6efe2`。クリーム色のホーロー。
- 富士見台: 柿色 `#e25b2a`。坂の上、夕方の家の側。
- 溝の口駅南口: 藍 `#1f4b6e`。駅の夜、改札を出た側。
- 東急バス: 赤 `#c1121f`。
- 川崎市バス: 緑 `#0e7a3d`。

文字は丸ゴシックで、数字は画面の主役にする。分数と時刻以外は小さくする。説明で分かってもらうのではなく、色と大きさで分かってもらう。

トップ画面に書いてよい言葉は「富士見台発」と「溝の口駅南口発」だけ。アプリ名 BusNow!! は、ホーム画面に置いたときの名前と、この文書の名前である。看板の上には載せない。

## トーン

急かさない。駅の電光掲示板のように正確で、紙の時刻表のように静か。エラーのときは「うまく取れなかった」と停留所の言葉で言い、取れたほうだけを見せる。深夜にバスがなければ、ない、と大きく言う。次の朝の3本は、時刻表の側で出す。
