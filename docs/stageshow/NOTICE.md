# Stageshow

README の画像は、[benjitaylor/skills](https://github.com/benjitaylor/skills) の Stageshow（MIT）で描きました。使ったコミットは `802057409787133703c56001080169e347305572` だけです。

キット一式（`kit/`）と、`assets/app-icons.ts`、`kit/brands/` は、このリポジトリに入れていません。画面は BusNow の看板（`src/app/globals.css` の色と形）と、CSS で描いた部品だけです。他社のロゴは使っていません。

撮影のときだけ、Noto Sans JP（SIL Open Font License）の 500 / 700 / 900 を読みました。フォントファイルは同梱していません。

ここの `.tsx` は、その撮影用シーンの写しです。アプリのビルドには使いません。先頭の `@ts-nocheck` は、キットが無い状態で型検査が止まらないようにするためです。
