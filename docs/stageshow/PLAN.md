# 計画

README は白いページ。画像そのものが停留所の絵になる。

- ヒーローは PC 幅の静止画。設計は 960×640。アスファルト（`#241c16`）の上に、クリーム色のホーロー看板。上と左右は同じ余白、下だけ薄く消える。消えるところは、続きを示す薄い棒だけ。言葉のある行は、その上で全部読める。
- iPhone 幅は、同じ看板が Phone の中でカウントダウンする。設計は 400×520。上から一つの余白、下は画面の外へ出る。390px では、電話を寄せた別の置き方にする。
- 見た目は BusNow の画面。柿色の帯、丸ゴシック、大きな分数、会社の色の丸い札。停留所・系統・会社は架空（さくら台、駅前ロータリー、系統 A12、あかね交通、みどり交通）。
- 動きは 5 → 4 → 3 → 2 と数字が回り、2 で一拍置く。そのあと「更新中」になって 5 に戻る。止まった絵は、あと 2 分。
- ロゴ、他社のアイコン、実在の地名と会社名は置かない。
